19:T11a4,<p>TC39 has an upcoming <a href="https://github.com/tc39/proposal-decorators">proposal</a> for decorators, that decorates class methods. That is different from just decorating fucntions, which has been around forever.</p>
<p>Let's explore some useful function decorators in this post.</p>
<h3><code>unary</code></h3>
<p><code>unary</code> is a function decorator that makes it possible to invoke the function with only the first argument. This is useful when you need the function to be passed a method argument, where multiple arguments are passed to the argument function.</p>
<p>Here is an implementation -</p>
<pre><code class="language-js">const unary = fn => (fn.length === 1) ? fn : function(firstParam) {
      return fn.call(this, firstParam);
};
</code></pre>
<p>Methods like <code>map</code>, <code>filter</code>, <code>forEach</code> all pass multiple arguments to the method argument.</p>
<p>So a call like <code>['first', 'second'].forEach(console.log)</code> is essentially equivalent to <code>['first', 'second'].forEach((ele, ind, list) => console.log(ele, ind, list))</code>.</p>
<p>You can decorate <code>console.log</code> function with <code>unary</code>, so <code>console.log</code> will ignore the second and third arguments.</p>
<pre><code class="language-js">['first', 'second'].forEach(unary(console.log));
// 'first'
// 'second'
</code></pre>
<h3><code>once</code></h3>
<p><code>once</code> decorates the function by making sure it is executed only once, in spite of getting invoked multiple times.</p>
<p>Here is a implementation -</p>
<pre><code class="language-js">const once = fn => {
  let done = false;
  const noop = () => {};
  return (...args) => done ? noop.call() : (done = true, fn.apply(null, args));
};
</code></pre>
<p>Now, when you decorate a function with <code>once</code>, any further invocation after the first invocation of the decorated function will result in a no-operation call.</p>
<pre><code class="language-js">const initMethod = () => console.log('Initializing the process';
const init = once(initMethod);
init();
// Initializing the process
init();
// no-op call, no output
</code></pre>
<h3><code>throttle</code></h3>
<p><code>throttle</code> decorates the function to wait till the given duration, before any subsequent invocations. The following is a simple diagram to explain what goes in with throttling. The first action is executed, but all subsequent invocations till the duration expires, all simply ignored.</p>
<pre><code class="language-ascii">                              throttle
+1+ +2+ +3+ +4+ +5+ +6+     +-------------->   +1+             +5+
+---duration---+                               +---duration--+ +---duration--+
</code></pre>
<p>Here is a sample implementation -</p>
<pre><code class="language-js">const throttle = (fn, duration) => {
  let shouldTheFnWait = false;
  return function(...args) {
    if (!shouldTheFnWait) {
      fn.apply(this, args);
    } else {
      setTimeout(() => { shouldTheFnWait = true; }, duration);
    }
  }
};
</code></pre>
<pre><code class="language-js">const testFn = () => console.log('print here?');
const decoratedTestFn = throttle(testFn, 1000);
decoratedTestFn(); // print here?
decoratedTestFn(); // nothing happens
setTimeout(decoratedTestFn, 1000); // print here, again as 1 second of throttle has elapsed.
</code></pre>
<h3><code>debounce</code></h3>
<p><code>debounce</code> decorates the function to space out the funciton invocations with the given duration. The following is a diagram to illustrate it. A burst of function invocations received are spaced out with the given duration.</p>
<pre><code class="language-ascii">                        debounce
+1+ +2+ +3+ +4+ +5+    +-------------->               +1+                +5+
+---duration---+                         +---duration---+   +---duration---+
</code></pre>
<p>Here is a sample implementation -</p>
<pre><code class="language-js">const debounce = (causeFn, duration) => {
  let timeout;
  return function(...args) {
    let effectFn = () => {
      timeout = null;
      causeFn.apply(this, args);
    }
    clearTimeout(timeout);
    timeout = setTimeout(effectFn, duration);
  }
};
</code></pre>
<pre><code class="language-js">const testFn = () => console.log('print here?');
const decoratedTestFn = debounce(testFn, 1000);
decoratedTestFn(); // print here? after 1 second
decoratedTestFn(); // nothing happens
setTimeout(decoratedTestFn, 1000); // print here, again as 1 second of throttle has elapsed.
</code></pre>
