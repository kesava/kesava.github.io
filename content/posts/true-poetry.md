# True poetry

```
haracūḍā hariṇānka vakratayu, gālāntasphuraccanḍikā
paruṣōdgāḍhapayōdhara sphuṭataṭī paryantakāṭhinyamun‌,
sarasatvaṁbunu saṁbhavince nanagā satkāvyamul‌ dikkulan
jirakālaṁbu naṭincucunḍu gavirājīgēharangaṁbulan‌!
```
