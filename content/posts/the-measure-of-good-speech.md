# The measure of good speech

```
*nānr̥gvēdavinītasya nāyajurvēddhāriṇaḥ.
nāsāmavēdaviduṣaśśakyamēvaṁ vibhāṣitum*
```

```
None but one steeped in Rig, Yajur, and Sama veda
Could speak with such shining clarity and grace.
```

```
*nūnaṁ vyākaraṇaṁ kr̥tsnamanēna bahudhā śrutam.
bahu vyāharatānēna na kiñcidapaśabditam*
```

```
Surely he's mastered all of grammar's rules
Not a word slips, not a sound falls apart.
```

```
*na mukhē nētrayōrvāpi lalāṭē ca bhruvōstathā.
anyēṣvapi ca gātrēṣu dōṣassaṁviditaḥ kvacit*
```

```
Not on his face, nor in his gaze,
Nor brow, nor limb, does fault find place.
```

```
*avistaramasandigdhamavilambitamadrutam.
urasthaṁ kaṇṭhagaṁ vākyaṁ vartatē madhyamē svarē*
```

```
His speech, clear and measured, neither rushed nor slow—
Steady in tone, from chest to throat it flows.
```

```
*saṁskārakramasampannāmadrutāmavilambitām.
uccārayati kalyāṇīṁ vācaṁ hr̥dayahāriṇīm*
```

```
His words are gentle, polished, pure and bright—
Not too quick, not too slow, yet they land just right.
```

```
*anayā citrayā vācā tristhānavyañjanasthayā.
kasya nārādhyatē cittamudyatāsērarērapi*
```

```
His vibrant words rise from heart, throat, and head—
Even a foe with a sword would pause instead.
```
