# Donut hole

```
తనకు గల్గు పెక్కు తప్పులు నుండగా
ఓగు నోగులెంచు నొరుల గాంచి
చక్కిలంబుఁ గాంచి జంతిక నగినట్లు
విశ్వదాభిరామ వినురవేమ !
```

```
O wonder of the world, heed Vemana's call!
We all have flaws,
but like a bagel mocking a donut's hole,
we are quick to find faults in others.
```
