# Sting today, Wise tomorrow

```
చాకి,కోక లుతికి చీకాకు పడజేసి
మైల తీసి లెస్స మడచినట్లు
బుద్ధి చెప్పువాడు గ్రుద్దితేనేమయా
విశ్వదాభిరామ వినురవేమ!
```

```
The washerman slaps cloth on stone,
not to harm but to cleanse.
So too a teacher's harsh word—
sting today, polish tomorrow.
```
