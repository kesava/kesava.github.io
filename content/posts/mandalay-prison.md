# Mandalay Prison

```
భరత ఖండంబే యొక గొప్ప బందెఖాన|
అందులో నున్న ఖయిదీలు హిందుజనులు
ఒక్క గది నుండి మార్చి వేరొక్కగదిని
బెట్టుటెగాక చెరయంచు వేరెగలదె
```

```
India is one great prison,
And its people, captives within.
Moving them from one cell to another
Doesn't change the chains they wear.
```
