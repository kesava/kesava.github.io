# The Dignity of Moustache

```
ఇయ్యగ నిప్పించగ గల
యయ్యలకే గాని మీసమందరి కేలా
రొయ్యకు లేదా బారెడు
కయ్యానికీ కుందవరపుకవి చౌడప్పా.
```

```
What use is a grand mustache, tell me -
If it can't command, or call for aid?
What pride has the shrimp's fine  whiskers,
If not to duel, O Chowdappa?
```
